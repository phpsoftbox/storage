# S3

`S3Storage` принимает конфигурацию, совместимую с S3:

- `bucket` — имя бакета.
- `key` — access key.
- `secret` — secret key.
- `endpoint` — URL S3 endpoint (по умолчанию `https://storage.yandexcloud.net`).
- `region` — регион (по умолчанию `ru-central1`).
- `prefix` — общий префикс для ключей (опционально); нормализуется как путь, `..` запрещено.
- `use_path_style_endpoint` — использовать path-style URL (по умолчанию `true`).
- `baseUrl` — опциональный публичный URL (например CDN).

Пример с явной настройкой:

```php
use PhpSoftBox\Storage\Drivers\S3\S3Storage;

$disk = S3Storage::fromConfig([
    'bucket' => 'my-bucket',
    'key' => $_ENV['S3_KEY'],
    'secret' => $_ENV['S3_SECRET'],
    'endpoint' => 'https://storage.yandexcloud.net',
    'region' => 'ru-central1',
    'use_path_style_endpoint' => true,
]);
```

`url()` вернёт ссылку, сформированную из `baseUrl` (если задан) или из `endpoint`/`bucket`; сегменты ключа кодируются
`rawurlencode()`.

## Пути и префикс

Пути нормализуются так же, как в `LocalStorage` (`FileHelper::normalizePath()`): `a//b/./c` → `a/b/c`, сегмент `..`,
NUL-байт и пустой путь — `StorageException`, запрос в S3 при этом не отправляется. Поэтому при изоляции тенантов через
префикс (`StoragePathPrefixSwitcher`) ключ вида `../tenant2/x` не выходит за префикс. `..` внутри имени
(`report..v2.pdf`) допустимо.

## Операции

- `put($path, $contents, $options)` — `$options` передаются в `PutObject` как есть (`ContentType`, `CacheControl`,
  `Metadata`, `ACL`, …); `Bucket`, `Key` и `Body` опциями не переопределяются.
- `exists()` возвращает `false` только при ответе 404. 403, сетевые ошибки и 5xx — `StorageException`. Учтите: без
  права `s3:ListBucket` S3 отвечает на отсутствующий ключ 403, а не 404 — такому ключу нужен доступ на листинг.
- `list($prefix)` — все ключи внутри «каталога» `$prefix` (к нему добавляется `/`: `list('reports')` не захватит
  `reports-old/`), без префикса диска; листинг проходит все страницы `ListObjectsV2` (по 1000 ключей).
- `copy()`/`move()`/`rename()` — серверный `CopyObject` (для `move`/`rename` — плюс `DeleteObject`); содержимое,
  `Content-Type` и пользовательские metadata сохраняются.

## Свой клиент

`S3Storage` работает через `Contracts\S3ClientInterface` (`putObject`, `getObject`, `deleteObject`, `headObject`,
`listObjectsV2`, `copyObject`); для AWS SDK есть `AwsS3ClientAdapter`. `headObject()` должен возвращать `null` при 404
и бросать исключение при любой другой ошибке.
